# Euro 2024 Team Analyser 🇪🇺⚽

This Python script allows you to analyse any team from the Euro 2024 dataset.

## 🔍 What it does:
- Asks you to enter a team name (e.g. France, England, Spain)
- Filters the dataset to show only that team’s games
- Calculates:
  - Total goals scored
  - Total goals conceded
- Displays match results
- Cleans up attendance data for future analysis

## 📊 Data source:
The data is loaded from a Euro 2024 `.csv` file stored locally.

## 🛠️ Requirements:
- Python 3.x
- `pandas`
- `matplotlib`
- `seaborn`
